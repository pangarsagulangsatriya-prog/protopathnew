# BINARY AND DUPLICATE FILE REPLACEMENT INDEX

The following package contents were not duplicated into the Antigravity upload set:

## ZIP archives

ZIP files only duplicated other package content.

Their text contents were merged into:

```text
01_MASTER_CONTEXT_ALL_PACKAGE_TEXT.md
```

## PDF

The canonical PDF was converted into:

```text
02_CANONICAL_SCORE_COMPLETE_TEXT.md
```

Page numbers and source hash remain available.

## PNG diagrams

The diagrams were converted into structured descriptions and status records in:

```text
04_DIAGRAM_ASSET_TEXT_DESCRIPTIONS.md
```

## Full GeoJSON files

The full feature collections were converted losslessly at feature level into:

```text
data_chunks/*.jsonl
```

Each JSONL line preserves one complete original `Feature` object.
