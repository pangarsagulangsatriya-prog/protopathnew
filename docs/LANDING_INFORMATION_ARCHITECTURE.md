# Landing Page Information Architecture

## 01 WIP Announcement Bar
- **Position**: Global, above main navigation.
- **State**: Dismissible (localStorage), recoverable via bottom-left info icon.
- **Content**: Qualitative disclaimer ("PROTO PATH IS AN ONGOING WORK IN PROGRESS...").
- **Actions**: EXPLORE CURRENT WORK (Primary), FOLLOW THE PROCESS (Instagram link).

## 02 Navigation
- **Position**: Sticky/Global header.
- **Content**: PROJECT, EXPLORE, METHOD, EXHIBITION, ARCHIVE.
- **Styling**: Hover effects on links utilizing a 2px orange-red bottom border that scales up.

## 03 Hero & Data-to-Body Transformation
- **Position**: Top of the document body.
- **Content**: Bold context setting ("WHERE DO YOU DEPART FROM?") followed by an explanation of the artistic-research nature.
- **Visual**: A 4-stage interactive transformation graphic (Data -> Situation -> Body -> Output).
- **Actions**: ENTER THE CURRENT SCORE, FOLLOW THE PROCESS, READ THE METHOD.

## 04 Project Status
- **Content**: High-level status indicating "IN PROGRESS".
- **Progress Line**: A qualitative progress visualization mapping RESEARCHING, BUILDING, TESTING, PUBLISHING states.
- **Goals**: Communicates the next development steps and current public materials.

## 05 Selected Completed Examples
- **Content**: Grid of specific completed scores, notations, and views.
- **Cards**: Title, abstract description, status (e.g., COMPLETED EXAMPLE, WORKING PROTOTYPE), and an abstract SVG preview of the relevant notation/system.
- **Action**: OPEN EXAMPLE navigating to the specific `/explore?pair=X` or `/explore?step=Y` route.

## 06 How the System Works
- **Content**: A concise four-step reading chain (Data, Situation, Body, Output).
- **Function**: Clickable cards mapping directly to the Explore tab views to educate the user on the methodology.

## 07 Current Prototype Preview
- **Content**: Dark-themed banner emphasizing the "INTERACTIVE SCORE VIEWER".
- **Action**: Direct CTA to enter the prototype explore page.

## 08 Follow the Project / Collaboration
- **Content**: Closing CTA encouraging continued engagement and conversation.
- **Actions**: Instagram follow link, and a copyable project URL mechanism with visual confirmation.

## 09 Footer
- **Content**: Copyright, team credits, language toggle, data integrity verification badge.
